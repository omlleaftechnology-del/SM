# Швидко Мийка

Статический прототип сайта с анимацией автомойки. Сборка и установка зависимостей не нужны.

## Публикация через GitHub Pages

1. Создайте публичный репозиторий на GitHub.
2. Распакуйте ZIP и загрузите **содержимое** папки в корень репозитория: `index.html`, `.nojekyll` и `README.md`. Сам ZIP загружать не нужно. Если скрытый файл `.nojekyll` не виден, для этого сайта можно обойтись без него.
3. Откройте **Settings → Pages**.
4. В **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку **main** и папку **/(root)**, затем **Save**.
6. После завершения публикации ссылка появится в разделе Pages. Обычно она выглядит так: `https://USERNAME.github.io/REPOSITORY/`.

Ссылку можно отправить любому человеку. Сайт и исходники в публичном репозитории будут доступны всем.

## Локальный просмотр

Откройте `index.html` в браузере. Дизайн и анимация работают автономно; для Google Maps нужен интернет.

## Содержимое

- Анимация: пена → вода → сушка, автомобиль в стиле BMW.
- Три демонстрационных тарифа; цены и состав ещё не подтверждены.
- Подписка: «Скоро».
- Адрес: вул. Чкалова, 37 Б, Гостомель, Київська область, 08289.
- Карта Google Maps и отдельная ссылка для открытия карты.

Это дизайн-прототип без оплаты, заявок и серверной части.
